# Партия «Чикен Ган» — сайт предвыборной программы

Официальный сайт партии «Чикен Ган» для Хабаровского края. Цель проекта — сделать выборы прозрачными и дать жителям понятные инструменты контроля: проверку списков, подачу жалоб, публичную витрину программ кандидатов и открытый набор в комиссии.

## Особенности

- **Современный дизайн** в тёмной теме с неоновыми акцентами.
- **Шрифт Inter** — хорошая читаемость на любых экранах.
- **Плавная навигация**: скролл к секциям, подсветка активного пункта меню при прокрутке.
- **Адаптивность**: корректно отображается на мобильных устройствах и десктопах.
- **Наполненный контент**: программа, ценности, статистика, форма заявки.

## Как запустить

1. Создай папку проекта, например `chicken-gun-site`.
2. Внутри создай файлы: `index.html`, `style.css`, `script.js`.
3. Вставь в них соответствующий код.
4. Открой `index.html` в браузере.

Никакие сторонние серверы или базы данных не требуются — это статический сайт.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, переменные, медиа-запросы)
- JavaScript (DOM, события, scrollIntoView)
- Шрифт: Inter (Google Fonts)

## Кастомизация

Чтобы быстро поменять стиль под себя:

- **Цвета:** в `style.css` в блоке `:root` поменяй переменные `--bg-dark`, `--accent`, `--neon`.
- **Логотип:** вместо текста `.logo` можно вставить `<img>`.
- **Контент:** редактируй текст в `index.html` — структура уже готова.
